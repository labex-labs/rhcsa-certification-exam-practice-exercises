Este curso ofrece ejercicios prácticos para prepararse para el examen de Red Hat Certified System Administrator (RHCSA). A través de una serie de laboratorios desafiantes, desarrollarás y reforzarás las habilidades esenciales necesarias para la administración de sistemas Linux y la certificación RHCSA.
