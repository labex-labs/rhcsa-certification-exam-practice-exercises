Этот курс предлагает практические упражнения для подготовки к экзамену на сертификацию Red Hat Certified System Administrator (RHCSA). С помощью серии сложных лабораторных работ вы будете развивать и закреплять важные навыки, необходимые для администрирования Linux-систем и получения сертификата RHCSA.
