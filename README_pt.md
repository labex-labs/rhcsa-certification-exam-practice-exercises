Este curso oferece exercícios práticos para preparar para o exame Red Hat Certified System Administrator (RHCSA). Através de uma série de laboratórios desafiadores, você desenvolverá e reforçará as habilidades essenciais necessárias para a administração de sistemas Linux e para a certificação RHCSA.
